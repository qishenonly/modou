# modou（墨斗）

> 弹好线，放手干。

**[English](README.md) · [简体中文](README-CN.md)**

**modou（墨斗）** 是一个本地优先的编码 Agent。它以**桌面 GUI 为主要形态**——Electron + React，Claude Desktop 式布局——读懂你的项目、和你一起规划、替你改文件、跑命令、并验证自己的成果。所有读写都发生在你授权的目录内，安全边界清晰可见。

modou 的名字取自木工的**墨斗**——相传由鲁班发明的弹线工具。工匠把蘸墨的线绳绷紧一弹，在木料上留下笔直准线，木匠照线下料。modou 遵循同样的理念：**你弹线（意图、项目指令、权限边界），agent 照线干活，绝不越界。**

## 核心能力（GUI）

### 对话区

- **流式回复**：Markdown 渲染、代码自动高亮（hljs）、代码块带语言标签与复制按钮；无语言标签的代码块同样按块渲染。
- **思考过程**：模型推理折叠在「思考过程」里，可展开查看，不打断正文。
- **工具调用内联卡片**：Edit 带改前/改后 diff、Bash 显示命令与退出码、Web 工具标注来源——工具在对话流里按发生顺序呈现，像问答一样连贯。
- **待办清单**：todo 进度随轮次实时更新。
- **子代理时间线**：角色子代理折叠为活动摘要，展开可见过程文本与最近调用的工具（工具名 chips）。
- **上下文用量指示器**：对话区顶部细进度条，显示当前上下文占用 / 模型窗口；70% / 90% 分档告警，临近压缩红色提示，悬停查看分项核算。
- **计划模式卡片**：`/plan` 产出结构化计划，对话内直接批准 / 修改 / 拒绝。
- **逐条操作**：每条消息 hover 出现「复制」（assistant 可「重新生成」，user 可「编辑」回填输入框）。

### 侧栏（会话管理）

- **项目切换**：一个目录 = 一个项目；左上角随时切换，只读你授权的目录。
- **会话全文搜索**：搜索框对会话**内容**做全文检索（不再只是标题），命中项显示片段与命中数；可一键切到「全部项目」做**跨项目检索**（结果标注项目归属）。
- **命中跳转**：点击搜索结果恢复对应会话，并自动滚动定位到命中消息、短暂高亮。
- **会话管理**：键盘导航（↑/↓ + Enter）、批量选择删除、重命名、右键菜单（恢复 / 重命名 / 归档 / 导出 / 删除 / 复制 ID）。
- **归档**：归档会话从主列表隐藏，归档视图可移出或删除——历史不丢、列表不脏。
- **导出**：把整条会话导出为 Markdown（分享 / 归档 / 交接）。
- **定时任务 / 用量**：侧栏直通任务面板与用量面板。

### 输入区

- **图片 + 文件附件**：粘贴 / 拖拽 / 按钮添加；图片按图片附件处理，文本类文件（代码、文档、配置…）内容直接读入消息，其余类型明确提示跳过。
- **权限模式一键切换**：输入框右上角弹出沙箱范围 × 审批策略的选择（只读 / 工作区写 / 完全访问 × 逐次 / 按需 / 不拦截），保存即生效。
- **斜杠命令提示**：输入 `/` 弹出全部内置命令。
- **Cmd+K 统一命令面板**：一个搜索框检索三类入口——斜杠命令、历史会话、项目文件；方向键 + Enter 执行，Esc 关闭。

### 右侧文件面板（Cmd+Shift+F）

- **文件视图**：递归文件树（尊重忽略规则），点击文件在面板内预览内容（二进制 / 超大文件有兜底提示）。
- **变更视图**：以 git 工作区为主（`git status` + `git diff`）列出全部未提交改动，逐文件展开 unified diff；agent 本轮编辑过的文件（即使不在 git 变更里）有「本轮编辑」标注。

### 模型与扩展

- **多供应商模型管理**：Anthropic / OpenAI 兼容端点（DeepSeek / Kimi / Qwen / GLM / 任意中转站 / Ollama…）；模型列表可从上游 `/models` 一键拉取；状态栏**模型下拉**随时切换。
- **设置面板**：模型 / 权限安全 / 上下文 / MCP / Hooks / Skills / Agents / 外观 / 快捷键 / 关于。
- **MCP 可视化管理**：连接状态一览（已连接 / 连接中 / 失败），服务器增删、启用 / 停用、风险级别配置。
- **技能（SKILL.md）**：按需加载的「怎么做」知识；额外技能目录可文本添加或「浏览…」一键导入。
- **自定义角色（Agents）**：`.modou/agents/*.md` 角色剧本，GUI 内直接创建 / 编辑 / 删除。
- **Hooks**：生命周期钩子（SessionStart / UserPromptSubmit / PreToolUse / PostToolUse）可视化配置。
- **长期记忆**：文件式笔记（`.modou/memory/`），跨会话加载。
- **联网工具**：WebSearch / WebFetch，域名白名单 / 黑名单、重定向守卫。

### 自动化与反馈

- **定时任务**：cron 驱动的周期任务（"每晚 10 点跑一遍自我对标"这类），面板内增删改。
- **任务完成通知**：长任务在窗口失焦时发系统通知，带耗时。
- **用量与成本**：用量面板（token 柱状图）+ `/cost` 成本核算（按天 / 按会话）。
- **主题**：浅色 / 深色 / 跟随系统。

## 底层能力（core）

GUI 与终端版（TUI）共享同一套 core（事件流协议 Event↑ / Command↓，前端可替换）：

- **极简 agent loop**：没有工作流引擎、没有隐藏编排——模型负责决策，工具负责执行。
- **内置工具集**：`Read` / `Write` / `Edit` / `Grep`（ripgrep）/ `Glob` / `Bash` / `Task` / `Todo` / `Skill` / `Agent` / `Memory` / `WebSearch` / `WebFetch` / MCP。
- **权限正交模型**：沙箱范围 × 审批策略 + allow/deny 规则表 + 危险命令强制确认。
- **会话永不失忆**：持久化 / `/resume` 续聊 / 增量压缩 / prompt caching / `/context` 分项核算。
- **快照回滚**：`/rewind` 把项目还原到任意历史快照点，撤销 agent 的改动。
- **计划模式**：`/plan` 只读研究 → 结构化计划 → 批准后执行。
- **多供应商**：供应商差异收敛在适配层，契约测试兜底。
- **开放扩展标准**：MCP / AGENTS.md / SKILL.md。

## 环境要求

- **平台**：macOS 或 Linux。
- **GUI（推荐形态）**：Node.js 18+（Electron 构建与运行）、Bun 1.3+（构建 / 测试）。
- **CLI（TUI）**：Bun 1.3+（TypeScript 源码直跑）。

## 安装与启动

```bash
git clone <repo>
cd modou
bun install
```

**桌面 GUI**

```bash
bun run gui          # 构建 + 启动（生产形态）
# 或开发模式（热重载）：
bun run gui:dev
```

**终端 CLI**

```bash
bun run start        # 等价于 modou / mo
```

## 快速开始

1. 启动 GUI，首次进入选择项目目录（一个目录 = 一个项目）。
2. 打开「设置 → 模型」：添加供应商（Anthropic 或 OpenAI 兼容端点）→ 「从上游拉取模型」→ 设为当前。
3. 回到对话区输入你的任务，Enter 发送。

```text
帮我梳理一下这个项目的结构，并给核心模块补上单元测试
```

modou 会读懂项目、规划、改文件、跑命令、验证——写入与命令执行会弹审批确认，危险命令**始终强制确认**。

## 配置

modou 把两套机制分开：**配置**（给程序读的结构化设置）与**项目指令**（给模型读的自然语言）。

### settings.json

配置解析层级——后者覆盖前者：

1. 内置默认
2. `~/.modou/settings.json`（全局）
3. `<project>/.modou/settings.json`（项目）
4. `MODOU_*` 环境变量
5. CLI / GUI 选项

```json
{
  "provider": "openai-compat",
  "model": "deepseek-chat",
  "baseURL": "https://api.deepseek.com/v1",
  "permission": {
    "sandbox": "workspace-write",
    "policy": "on-request",
    "rules": [
      { "effect": "allow", "match": "npm test" },
      { "effect": "deny", "match": "git push", "tool": "bash" }
    ]
  },
  "mcp": {
    "servers": {
      "filesystem": {
        "command": "npx",
        "args": ["-y", "@modelcontextprotocol/server-filesystem", "/repo"],
        "risk": "read"
      }
    }
  },
  "web": {
    "allowedDomains": ["example.com"],
    "deniedDomains": ["ads.example.com"],
    "timeoutMs": 15000,
    "maxBytes": 262144
  },
  "maxTurns": 10,
  "keepTurns": 6
}
```

### 环境变量

`MODOU_*` 与设置字段一一对应，优先级高于文件；API Key 读标准供应商变量（`OPENAI_API_KEY` / `ANTHROPIC_API_KEY`）。

### 项目指令（AGENTS.md）

模型的工作规则来自指令文件，从工作目录向上收集：全局 `~/.modou/AGENTS.md` → 项目根 → 子目录（兼容 `CLAUDE.md`）。总量上限 32KB，触顶截断会告警。

### 技能（SKILL.md）· 自定义角色（Agents）· 长期记忆（Memory）

- **技能**：遵循 [Agent Skills](https://agentskills.io) 开放标准，把含 `SKILL.md` 的目录放进任一层级即生效；渐进式披露（只有 name + description 常驻上下文，正文按需加载）。
- **角色**：`.modou/agents/<name>.md`（frontmatter：name / description / allowedTools / model + 正文提示词），工具白名单真正强制。
- **记忆**：`.modou/memory/<key>.md` 纯文本笔记，`memory_write / read / list` 读写，跨会话启动注入。

## 工作原理

两个包，一条契约——外加消费它的界面：

- **`core`** — agent loop、工具执行管线、权限与上下文管理。零 UI 依赖，只对外发事件。
- **`tui`** — 基于 Ink 的终端界面（`modou` / `mo`）。
- **`gui`** — Electron + React 桌面界面（Claude Desktop 式布局），是当前主要产品形态。

界面里看到的一切都是**事件**，你做出的每个操作都是**命令**。这条契约让内核与前端彻底解耦——GUI、TUI、未来的 SDK / 编辑器集成，都只是同一事件流的不同消费者。

所有副作用只走**一条工具管线**——权限、钩子、审计全部挂在唯一咽喉上，刻意不存在第二条路径。

## 安全模型与局限

- **沙箱范围**：只读 · 工作区可写 · 完全访问
- **审批策略**：不信任 · 按需 · 从不
- **规则表**：allow/deny 前缀匹配 + 内置危险命令黑名单（如 `rm -rf`、force-push）。危险命令即使在 `never` 策略下也**强制逐次确认**。
- **目录边界**：先解析真实路径（跟随符号链接、展开 `..`）再校验，杜绝字符串前缀绕过。
- **MCP / 联网边界**：MCP 工具在沙箱边界之外运行，缺省 `network` 风险需审批，审批弹窗带来源前缀；联网工具默认需批准，域名白名单 + 重定向逐跳校验，抓回内容标记为外部数据（数据非指令）。

**诚实记录的限制。** shell 命令的前缀匹配是可以绕过的：`bash -c "rm -rf x"`、`eval`、`;` 串联、别名——静态字符串匹配挡不住有意的绕过。因此规则表只是「防手滑、防模型莽撞」的深度防御一层，不是安全边界。真正的隔离依赖 OS 级沙箱（Seatbelt / Landlock / 容器），在它交付之前：只在你可以接受数据丢失的目录里运行 modou；对任何在工作目录之外写文件或执行命令的审批弹窗，多看一眼再点。

# modou（墨斗）

> 弹好线，放手干。

**[English](README.md) · [简体中文](README-CN.md)**

**modou**（墨斗）是一个终端编码 Agent：读懂你的项目、和你一起规划、替你改文件、跑命令、并验证自己的成果——全程发生在你的终端里。

modou 的名字取自木工的**墨斗**——相传由鲁班发明的弹线工具。工匠把蘸墨的线绳绷紧一弹，在木料上留下笔直准线，木匠照线下料。modou 遵循同样的理念：**你弹线（意图、项目指令、权限边界），agent 照线干活，绝不越界。**

## 特性

- **极简、由模型驱动的 agent loop。** 没有工作流引擎、没有隐藏编排、没有意图分类器。模型负责决策，工具负责执行；所有「智能」来自模型、工具描述与系统提示词。
- **经过验证的内置工具集。** `Read`、`Write`、`Edit`、`Grep`（基于 ripgrep）、`Glob`、`Bash`——头部编码 Agent 共同验证的最小完备集。其余一切可插拔。
- **多供应商开箱即用。** Anthropic、OpenAI 兼容端点、DeepSeek / Kimi / Qwen / GLM，以及通过 Ollama 接入的本地模型。适配器以契约测试兜底，供应商差异绝不渗透进 agent loop。
- **权限可调、默认安全。** 沙箱范围（只读 / 工作区可写 / 完全访问）× 审批策略（不信任 / 按需 / 从不）正交组合，叠加 allow/deny 规则表与硬性目录边界。安全是默认值，自主需要显式开启。
- **会话永不失忆。** 会话日志持久化、`/resume` 续聊、增量压缩（不塌缩上下文）、prompt caching，以及 `/context` 的分项 token 核算。
- **懂你的项目。** 读取 `AGENTS.md`（兼容 `CLAUDE.md`），按 全局 → 项目 → 子目录 三级叠加。
- **走开放标准的扩展体系。** MCP 工具、SKILL.md 技能、生命周期钩子、自定义斜杠命令、自定义 agent——不发明私有格式，复用你已有的生态。

## 环境要求

- **Node.js** 20+（或 Bun）
- **平台：** macOS 或 Linux

## 安装

```bash
npm install -g modou
```

## 快速开始

```bash
cd your-project
modou "这个代码库的鉴权是怎么流转的？"
```

然后继续对话，常用斜杠命令：

| 命令 | 作用 |
| --- | --- |
| `/help` | 查看所有斜杠命令 |
| `/model` | 会话中途切换模型 |
| `/context` | 按分项查看 token 占用 |
| `/compact` | 压缩会话历史 |
| `/resume` | 恢复之前的会话 |

## 工作原理

三个包，一条契约：

- **`core`** — agent loop、工具执行管线、权限与上下文管理。零 UI 依赖，只对外发事件。
- **`tui`** — 基于 Ink 的终端界面，是 core 事件流的纯消费者。
- **`cli`** — 可执行入口（`modou`，别名 `mo`）。

界面里看到的一切都是**事件**，你做出的每个操作都是**命令**。这条窄契约让内核与前端彻底解耦——无头模式、SDK、编辑器集成，都只是同一事件流的不同消费者。

所有副作用只走**一条工具管线**——权限、钩子、审计全部挂在唯一咽喉上，刻意不存在第二条路径。

## 安全模型

- **沙箱范围：** 只读 · 工作区可写 · 完全访问
- **审批策略：** 不信任 · 按需 · 从不
- **规则表：** allow/deny 前缀匹配，内置危险命令黑名单（如 `rm -rf`、force-push）
- **目录边界：** 先解析真实路径（跟随符号链接、展开 `..`）再校验，杜绝字符串前缀绕过

规则与审批是纵深防御的一层：防手滑、防模型莽撞。真正的隔离边界——OS 级沙箱（Seatbelt / Landlock）——在计划之中。
